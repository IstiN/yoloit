# Note: n_0013_f397

yoloit: real-PTY tests must set Pty.debugUsePty2Override = true — `flutter test` does not build the flutter_pty FFI framework for the host tester (dlopen fails), while pty2 resolves libc symbols via @Native/DynamicLibrary.process() and works. Also `flutter analyze` resolves the pty_wrapper.dart conditional export to the WEB stub, so any static member (debugUsePty2Override/usePty2) must be mirrored in both pty_wrapper_stub.dart and pty_wrapper_io.dart. Example: test/unit/features/terminal/pty_shift_enter_wire_test.dart (Shift+Enter ESC CR/ESC LF contract, issue #15).
