# Note: n_0019_36b1

Flutter desktop context-menu gotcha (YoLoIT file tree): nested GestureDetectors with onSecondaryTapDown ALL fire (tap-down callbacks bypass the gesture arena), stacking two menus. Switching to onSecondaryTapUp breaks entirely on the board canvas because InteractiveViewer's ScaleGestureRecognizer accepts ALL mouse buttons (default allowedButtonsFilter) and wins the pointer-up arena sweep. Reliable pattern: Listener.onPointerDown filtering event.buttons == kSecondaryButton, with explicit pointer-id consumption set so the outer (background) listener skips events a tile already handled (child listeners fire before parents in hit dispatch; PointerDownEvent.position is global). Implemented in lib/features/board/plugins/builtin/filetree_plugin_vm.dart (_consumedSecondaryPointers). Note: TapDownDetails has no pointer id — that's why Listener, not GestureDetector.
