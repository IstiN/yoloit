# Note: n_0021_487c

YoLoIT: a monolithic `flutter test --coverage` wedges on this repo/machine after ~2k tests (runner goes idle at 0 CPU, no error; reproducible at ~1900-2030 tests). Fix: run the suite in shards of <=25 test files per `flutter test` invocation with a log-activity watchdog (150s of silence = kill), then merge per-shard LCOV with `lcov -a ... -o coverage/lcov.info --ignore-errors empty`. Working driver: /tmp/yoloit_coverage_shards.py pattern. Golden tests under test/golden also fail with ~44 pixel diffs on this machine on clean HEAD (environmental rendering difference) — do not treat as regressions; verify via `git stash -u` + rerun on clean HEAD before blaming changes.
