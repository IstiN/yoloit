# Note: n_0029_03ed

HARD RULE (owner directive): NEVER restart, kill, pkill, or otherwise touch the user's running yoloitd daemon or tmux sessions on this machine. Restarting yoloitd wipes ALL the user's live terminal panels in yoloit. New daemon binaries get picked up only when the owner restarts the app themselves. Before any broad `pkill`/`kill` (e.g. cleaning hung flutter_tester), filter precisely by PID list reviewed first — never pattern-kill anything that could match yoloitd/tmux/user terminals. Applies to me and all subagents; include it in every spawned task's constraints.
