# Note: n_0017_8703

yoloit release pipeline (verified on v1.0.295, 2026-09-20): `gh workflow run release.yml --field version=auto` (Release All Platforms) creates the tag+release and dispatches build-macos/build-windows/build-linux. The macOS workflow runs on a SELF-HOSTED runner (another Mac of the user; has preinstalled Flutter 3.44.4 at ~/.local/flutter) — pinned to Flutter 3.47.4 via subosito/flutter-action since js_widget_runtime ^0.4.121 needs flutter >=3.47. Notarization uses runner secrets MACOS_NOTARIZE_APPLE_ID/TEAM_ID/APP_PASSWORD; Apple app-specific passwords get revoked when the Apple ID password changes (recurring 401 cause) — consider migrating to App Store Connect API key (notarytool --key/--key-id/--issuer). Per-arch DMGs upload as workflow artifacts via actions/upload-artifact; the final release job attaches yoloit-macos-{arch}-1.0.X.dmg + versioned and unversioned -mac.zip zips (the unversioned ones + latest-mac.yml are required by the electron-updater manifest). `gh run rerun <id> --failed` re-runs only failed jobs — used when one arch flakes on runner network.
