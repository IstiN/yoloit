# Note: n_0018_ded2

YoLoIT crashed 2026-10-01 (app 1.0.295) with SIGABRT: super_clipboard/super_native_extensions 0.9.1 builds its Rust code with panic = "abort", so any internal panic in SystemClipboard.read() killed the whole process (uncatchable from Dart). Fix: migrated to the `pasteboard` package (0.5.0) — tiny Swift/C++ plugin using a plain MethodChannel (errors are catchable PlatformExceptions), no Rust/FFI. SmartClipboardPasteService/ClipboardFileService read text via Flutter's Clipboard.getData first, then Pasteboard.image for screenshots (macOS plugin always returns PNG; other platforms' bytes are extension-sniffed via magic bytes). Trade-off kept: clipboard with BOTH image and text pastes the text. super_clipboard was removed from pubspec and macos/Podfile.lock.
