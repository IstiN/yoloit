# Note: n_0020_eaf5

Terminal TUI scroll lost after app restart: runtime backend (yoloitd Go daemon) sessions survive restarts; the Flutter xterm emulator is recreated and replays only the recent output ring, so DEC private modes (alt buffer 47/1047/1049, mouse reporting 1000-1015) set long ago are lost → wheel scrolls local scrollback instead of reaching the TUI. Fix: yoloitd session.go trackModes() parses CSI ?Pm h/l from PTY output (with split-sequence carry) and returns `modes` in POST /sessions; Dart re-applies them via buildTerminalModeRestoreSequence() before subscribing to output (board_terminal_session_manager._spawn + terminal_cubit._attachProcessToSession). Daemon binary tools/yoloitd/yoloitd must be rebuilt (go build) and is picked up via debug live path or the runtime-restart banner.
