# Note: n_0016_4925

yoloit dev build (./run.sh, product "YoLoIT (dev).app") uses separate config root ~/.config/yoloit-dev with its own cli.port and its own boards (SharedPreferences). The `yoloit` CLI reads the port from ~/.config/yoloit/cli.port (installed app) — to target the dev instance use YOLOIT_CLI_PORT=<port from ~/.config/yoloit-dev/cli.port>. With both apps running, CLI commands and board:screenshot go to whichever owns the default port — a stale minimap screenshot "without the fix" meant the old installed app answered.
