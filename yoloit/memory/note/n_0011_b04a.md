# Note: n_0011_b04a

run.sh execs flutter run so it inherits the run-session TTY: flutter_tools installs its interactive r/R/q key handler only when stdin is a TTY (stdinHasTerminal), so the old FIFO-stdin setup silently disabled hot reload/restart. Run panel quick actions deliver keys via tmux send-keys (RunService.sendStdin); hot_reload.sh matches the run session by pane working directory (pane_current_path), never by session-name sort — another project's yoloit_run_cli_* session can sort later and would receive the keys.
