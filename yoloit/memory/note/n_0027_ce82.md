# Note: n_0027_ce82

quickjs_runtime: root cause of 'silent undefined eval' / CI failures on GitHub ubuntu runner (fixed in 0.4.8, commit 0355922) — Dart VM migrates isolates between OS threads when not pinned in FFI; QuickJS anchors its stack-overflow limit to the creating thread's stack base. An eval on a migrated thread spuriously throws SyntaxError "stack overflow" at parse depth 0, and rendering that error overflows again → JS_ToCString returns NULL → eval silently returns undefined (no errMsg). Symptom signature: pool/async tests over attached main runtime return 'null' reproducibly on multi-core Linux runners, never on macOS. Fix pattern: JS_UpdateStackTop() at every JS entry point (qjs_eval, qjs_execute_pending_jobs*), race-free under one-runtime-per-isolate. Diagnosis was proven via CI instrumentation, not guessed. Related: quickjs CI test.yml has timeout-minutes: 20 because 'dart test' on GH windows runner hung >2.5h in native-assets/hook phase (separate unresolved issue — GH windows jobs may also just sit in queue backlog; no cancel rights without admin token).
