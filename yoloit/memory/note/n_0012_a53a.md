# Note: n_0012_a53a

yoloit macos/Runner.xcodeproj/project.pbxproj hard-references SwiftPM packages (FlutterGeneratedPluginSwiftPackage plus the local FlmMLXRuntime → mlx-swift), and both workspace Package.resolved files are committed — do NOT disable Swift Package Manager (flutter config --enable-swift-package-manager) or remove those refs, or xcodebuild fails to resolve plugins on the pinned Flutter 3.44.4 toolchain.
