# Note: n_0020_2ed3

YoLoIT crash 2026-10-12 (SIGABRT in WKUserContentController addScriptMessageHandler) root cause: webview panel's YoloNewTab JS channel remove→add pairs were fire-and-forget and could interleave (configure/detach/remove race) → WebKit NSException "duplicate script message handler" kills the process. Fix: WebViewManager serializes all channel mutations per panel via _channelQueues FIFO; queue entries self-remove via whenComplete because a then-listener registered on a future that completed in a defunct test zone never fires (cross-test singleton pollution).
