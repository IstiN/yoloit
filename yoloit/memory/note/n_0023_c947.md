# Note: n_0023_c947

quickjs_runtime (репо ~/git/quickjs_runtime, pub-владелец этого аккаунта) с v0.4.3 имеет полноценный MSVC-порт QuickJS: native/quickjs/msvc/msvc_compat.h (ssize_t, HUGE_VAL, нейтрализация __attribute-spelling'ов, stdin/fileno/clock_gettime-шимы), hook/build.dart подбирает clang-cl+lld-link на Windows, DIRECT_DISPATCH 0 под _MSC_VER (switch-интерпретатор как у Emscripten). При обновлении/реимпорте исходников QuickJS обязательна проверка препроцессором: clang-cl /Zs с -D_MSC_VER + -include msvc_compat.h + -DDIRECT_DISPATCH=0 -DCONFIG_VERSION=..., иначе CI ловит C2xxx/LNK2019 раундами (история: релиз yoloit v1.0.298 потребовал 5 раундов 0.4.3→0.4.7: 100+ → 9 → 2 → 1 → 0 ошибок). Скрытый нюанс: macOS ld молча терпит unresolved symbols в dylib — LNK-подобные баги видно только на Windows. Все платформы собирают QuickJS БЕЗ CONFIG_BIGNUM → BigInt/BigFloat/BigDecimal недоступны (decimal-пути libbf не прогнаны под MSVC); включение — отдельная задача.
