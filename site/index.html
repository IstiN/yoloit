Features

CLI-first control

Every action is exposed through the `yoloit` CLI so agents and scripts can drive the UI.

Infinite board + panels

Notes, kanbans, checklists, tables, charts, calendars, code snippets, webpages, and more.

Native terminal sessions

Spawn persistent terminal sessions for Copilot, Cursor, Codex, Kimi, OpenCode and custom agents.

Runners & tasks

Start, stop, and restart long-running commands directly from the board.

AI chat panels

Bring your own API keys and chat with OpenAI, OpenRouter, Ollama and agent-specific adapters.

Collaboration

Share your board over the local network so teammates can follow along from a browser.

Custom JS widgets

Build your own panels with JavaScript and a declarative JSON UI API.

Powerful CLI

Drive everything from the terminal

yoloit
$ yoloit board:create "Sprint 42"
✓ Board Sprint 42 created
$ yoloit panel:create "Sprint 42" board.kanban "Sprint Board"
✓ Panel Sprint Board added
$ yoloit panel:create "Sprint 42" board.note "API Design"
✓ Panel API Design added
$ yoloit do "Sprint 42" "API Design" setState '{"markdown":"## Endpoints\n- GET /boards"}'
✓ State updated
